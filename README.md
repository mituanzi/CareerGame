# 职业觉醒实验室

> **世界上最好的工作，是终身学习者在自由市场中的创造性表达。**
>
> 我们想做的，是陪你一起，找到属于你的那一种。

## 🎮 这款游戏在回答什么问题？

很多人都在问：
- “我到底适合做什么？”
- “现在的工作，是不是在消耗我？”
- “如果重新来过，我该往哪里走？”

《职业觉醒实验室》不是“测一测你像哪个动物”的娱乐测试，而是一场**面向真实职场生存的模拟实验**。

我们相信：
- **最好的工作**，不是“钱多事少离家近”，而是你可以在其中持续学习、在自由市场中与他人公平交换、并用你的方式创造价值的那个位置。
- **而第一步**，是从理解自己开始：你的特质、你的底线、你愿意为哪一种生活买单。

在这个文字冒险里，你需要在“能量”、“意义”、“收益”三者之间不断权衡。  
每一个选择，都在悄悄回答一个问题：  
**“我真正愿意为什么样的生活付出代价？”**

## 🧭 它能帮你做什么？

### 1. 看清你的“职场人格原型”

通过你在游戏中的选择轨迹，我们会提炼出你的主导特质：
- 技术专精型 / 资源整合型
- 自由自主型 / 安全稳定型
- 服务奉献型 / 挑战突破型

这对应着你在真实职场中的“出厂设置”：你天生偏向哪一类问题，更容易在哪种环境中发光。

> **价值层（你“想要什么”）** 与下面的**认知层（你“怎么干”）** 互为正交的两维，交叉后生成“职业认知”建议。

### 1.5 看清你的“认知风格”（MBTI 风格维度）

在沿用原有 14 道通用题与 6 大职业剧本的同时，每个选项都额外携带一组 `cog` 认知标签（外倾/内倾、实感/直觉、思考/情感、判断/知觉）。玩家**一道题都不用多加**，结束时即可由选择轨迹推断出类似 `INFP` 的认知类型与凯尔西气质（理性者 / 守护者 / 理想者 / 艺术者），并给出 4 个轴的清晰度百分比。

- **学生线**：报告在“人格原型”之后叠加「认知风格」卡片与「职业认知（价值原型 × 认知风格）」交叉建议，把“你追求什么”和“你习惯怎么干”合成可落地的职业姿态。
- **职场线**：在“深度诊断”之后追加认知提示，提示倦怠往往发生在工作要求与个人认知习惯相悖时。

> 注：认知类型为**连续倾向**的透镜，而非命运判决书；样本不足时相关轴会标注“样本不足”。

### 2. 找到与特质匹配的“剧本”

游戏提供 **6 大职业剧本**：
- 程序员、金融民工、央企职员
- 体制内、高校青椒、医务工作者

我们会根据你的特质，为你推荐：
- **学生线**：更可能让你“创造性表达”的职业方向。
- **职场线**：你现在的工作，是放大了你的特质，还是在持续消耗你。

### 3. 诊断你与当前工作的“匹配度”

游戏结束时，你会收到一份基于真实决策的“体检报告”，而不是一句空洞的“你适合创业”。
报告会回答：
- 你当前的状态是“健康 / 亚健康 / 危险”？
- 你是否踩中了“金手铐陷阱”或“职业倦怠”？
- 更重要的是：下一步，你可以做什么。

## ✨ 核心亮点

### 🌗 动态主题，沉浸体验
不同职业不再只是“换个图标”，而是换一种“活法”的代入感：
- 选择**程序员**，界面变为极客灰绿，在代码与焦虑之间寻找成就感；
- 选择**金融民工**，界面变为财富金黄，在数字与酒局之间权衡底线；
- 选择**体制内**，界面变为稳重青蓝，在原则与前途之间找到平衡。

### 🔬 双线诊断，深度洞察
根据你的身份（学生 / 打工人），生成不同侧重点的报告：
- **学生线**：侧重“人格特质 + 职业方向建议”，帮你少走弯路。
- **职场线**：侧重“健康度诊断 + 去留建议”，帮你识别是该调整、转型，还是坚持。

### 📚 百种剧情，真实扎心
- **6 大职业剧本**：覆盖典型职场路径，每一条都源自真实生活，拒绝悬浮。
- **26+ 专属事件**：每个职业均有 12 个深度定制事件，模拟真实困境。
- **14 个通用抉择**：关于规则、自由、责任、安全感的底层选择，塑造你的“职场人格”。
