## 🎮 关于游戏

《职业觉醒实验室》是一款基于现实职场逻辑的文字冒险游戏。

不同于传统的打怪升级，在这里，你唯一的对手是**生活本身**。你需要平衡“能量”、“意义”与“收益”三者的关系，在 26 个真实扎心的职场场景中做出抉择。

这是献给所有迷茫学生和职场人的一份**“生存模拟器”**。

## ✨ 核心亮点

### 🌗 动态主题，沉浸体验
不再是一成不变的黑白界面。
*   选择**程序员**，界面变为极客灰绿，敲击着代码与焦虑；
*   选择**金融民工**，界面变为财富金黄，周旋于数字与酒局；
*   选择**体制内**，界面变为稳重青蓝，平衡着原则与前途。
每一个职业都有专属的视觉主题和配色方案。

### 🔬 双线诊断，深度洞察
游戏结尾不再是简单的“输赢判定”，而是基于你的选择轨迹生成深度报告：
*   **学生线**：分析你的底层人格特质（技术型/资源型/挑战型...），并为你推荐最适合的职业剧本。
*   **职场线**：诊断你的职业健康度与人岗匹配度，揭示你是否处于“职业倦怠”或“金手铐”陷阱，并给出行动建议。

### 📚 百种剧情，真实扎心
*   **6大职业剧本**：程序员、金融民工、央企职员、体制内、高校青椒、医务工作者。
*   **26+ 专属事件**：每个职业均包含 12 个深度定制的专属事件，源自真实生活，拒绝悬浮。
*   **14 个通用抉择**：关于人性、规则、自由与安全的底层测试，决定了你的职场人格。

## 🕹️ 如何开始

本游戏为纯前端项目，无需服务器，点击如下网页即可使用: https://mituanzi.github.io/CareerGame/

选择你的身份（学生/打工人），开始觉醒之旅。
